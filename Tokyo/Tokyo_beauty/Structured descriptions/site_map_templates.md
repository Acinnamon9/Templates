# site_map_templates.md

## Purpose

This document defines **complete page flow templates**.

A page flow is the **sequence of sections that guide a visitor toward a conversion goal**.

The AI should:

1. Select a template based on page intent
2. Instantiate sections using `layout_patterns.md`
3. Populate them using `components.md`
4. Apply copy structures from `copy_patterns.md`

---

# Global Narrative Logic

Most high-converting pages follow this psychological progression:

```
attention
→ problem awareness
→ solution introduction
→ credibility
→ offer
→ conversion
```

The AI should prefer flows that respect this narrative structure.

# Template 1 — Lead Generation Landing Page

### Purpose

Capture a lead for:

* sales calls
* demos
* consultations
* downloads
* waitlists

---

### Page Flow

```
1 Hero
2 Problem
3 Mechanism / Solution
4 Benefits
5 Social Proof
6 Offer Explanation
7 FAQ
8 Final CTA
9 Footer
```

---

### Conversion Logic

The page must:

1. create clarity about the result
2. show the problem
3. introduce the solution
4. provide credibility
5. ask for conversion

---

### Notes

The **primary CTA appears in:**

```
Hero
Offer
Final CTA
```

Avoid adding CTAs in every section.

# Section Ordering Rules

The AI should respect these logical constraints:

### Rule 1

Hero must always appear **first**.

---

### Rule 2

Pricing should appear **after value is demonstrated**.

---

### Rule 3

Social proof should appear **before major conversion moments**.

---

### Rule 4

FAQ should appear **after the offer**.

---

# Conversion Points

Every page should include **2–3 strategic CTAs**.

Recommended placements:

```
Hero
After proof
Final section
```

Avoid:

```
CTA after every section
```

---

# Page Assembly Instructions for AI

When generating a website:

```
1 determine page intent
2 select sitemap template
3 instantiate sections
4 apply layout_patterns
5 insert components
6 apply copy frameworks
```

---

# Anti-Patterns

Avoid page flows that:

```
start with features before explaining the problem
present pricing too early
omit social proof
place CTA only once
create overly long pages without structure
```
