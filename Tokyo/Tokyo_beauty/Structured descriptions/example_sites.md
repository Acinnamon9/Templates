# example_sites.md

## Purpose

This document provides **reference websites that represent excellent design, clarity, and conversion structure**.

These examples help guide:

* layout decisions
* typography hierarchy
* motion design
* content density
* visual restraint

The AI should **learn patterns and principles**, not replicate the designs directly.

---

# Reference Categories

The sites are grouped by **design strengths**.

```text
Product clarity

```

# Product Clarity

## Stripe

Website:
[https://stripe.com](https://stripe.com)

### Why It Works

Stripe is a benchmark for **clarity and hierarchy in complex products**.

Key characteristics:

**1. Structured information hierarchy**

Content moves logically:

```text
problem
product explanation
features
developer documentation
```

Users can understand a complex platform quickly.

---

**2. Excellent layout rhythm**

Stripe uses strong vertical rhythm:

* large hero
* compact feature blocks
* dense documentation areas

This creates **visual pacing**.

---

**3. Diagram-driven explanations**

Stripe often explains features using:

```text
simple diagrams
product UI visuals
workflow graphics
```

This makes complex systems understandable.

---

**4. Balanced density**

Stripe balances:

```text
dense information
clean layout
```

The page never feels empty or overwhelming.

# Minimalist SaaS Design

## Linear

Website:
[https://linear.app](https://linear.app)

### Why It Works

Linear is a benchmark for **modern minimalist SaaS design**.

---

**1. Extreme visual restraint**

Linear avoids:

```text
heavy gradients
loud colors
busy layouts
```

Instead it relies on:

```text
typography
spacing
subtle motion
```

---

**2. Strong typography hierarchy**

Headlines are large and clear.

Body text is short and readable.

Users can **scan the page instantly**.

---

**3. Subtle motion design**

Animations are smooth and understated.

Examples:

```text
hover interactions
scroll fades
UI demonstrations
```

Motion reinforces understanding rather than distracting.

---

**4. Product-first visuals**

The interface itself becomes the hero visual.

This builds credibility because users see **the real product**.

# Key Patterns Across Great Websites

Across these examples, several patterns appear repeatedly.

---

## 1. Clear Hero Sections

Effective heroes communicate:

```text
what the product does
who it is for
why it matters
```

Within the first screen.

---

## 2. Visual Explanation

Great websites rely on:

```text
product screenshots
animations
diagrams
videos
```

Visuals often replace long text explanations.

---

## 3. Strong Typography Hierarchy

Good websites use:

```text
large headlines
short paragraphs
clear section separation
```

This improves readability.

---

## 4. Section-Based Storytelling

Most high-quality websites follow a narrative flow:

```text
problem
solution
features
benefits
proof
offer
```

This mirrors effective sales communication.

---

## 5. Minimal Design Systems

Good design systems rely on:

```text
limited color palette
consistent spacing
few font styles
reusable components
```

This creates visual coherence.

# Instruction for AI

When generating website designs:

1. Study these references for **structure and taste**.
2. Extract principles such as **hierarchy, pacing, and clarity**.
3. Combine these principles with the **design system and layout patterns**.
4. Produce original layouts that follow similar quality standards.

The goal is to create websites that feel **professional, modern, and credible**, while remaining **clear and conversion-focused**.
